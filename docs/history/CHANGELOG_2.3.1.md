# Exposure Desk 2.3.1-rc.1

Reliability repair over preserved 2.3.0-rc.1+5fd9435d84e583c6. Provider format rules and the pinned detector dependencies remain unchanged. Existing public discovery, source reconstruction, browser isolation, schedules, history, vault, explicit reveal/copy/full exports, owner-local artifacts and self-test remain available.

Application entry content, scripts, configuration and source maps receive bounded early turns. A weighted resource scheduler and a FIFO transport coordinator share the configured request, rate, concurrency, byte and duration limits with browser traffic. Failed page attempts count toward the page cap. Repeated failures in an optional route group defer further pages without preventing other groups/assets from being inspected. At most one controlled retry is made; Retry-After delta/date values are honored. A scan deadline stops queued/network/browser/engine work independently of operator cancellation.

Audit records separate DNS, connection, TLS, headers, body, preflight/rate/transport queue and analysis/offline-engine time. Each failed attempt has an identity, one outcome and one cause note. A timeout identifies its observed phase, not a remote cause. Network failures, cancellations, HTTP errors, policy events and intentional skips are distinct.

Known raster bodies and Next image renditions are intentionally skipped after local URL inspection. Distinct source images remain separate; signed/capability queries, unknown rendition parameters, SVG and non-image configuration URLs retain their meaning. Bounded expandable summaries replace hundreds of repetitive rows. Sitemaps, source maps, baseline responses and deployment checks use explicit types. A successful map requires valid source-map structure and analysis; an inspected 404 body or HTML fallback cannot supply that success.

Endpoint observations now retain exact matched URLs, literal source excerpts and positions, endpoint roles and specific remediation. Public image/object references do not prove bucket access. Metadata-only positions are unavailable. Information findings use Copy endpoint / View source evidence; credentials keep deliberate full-value controls. Focused retry previews exact safe URLs, excluded successful static URLs and fresh browser routes under the existing approved origins. Focused results remain incomplete for project-wide comparison.

Semantic analysis reserves mutation-safety and emission work, excludes unsafe unfinished modules explicitly, caches identical parsing and avoids repeated decoding of equivalent sources. Exact content reuse preserves distinct occurrences, including incomplete engine status when shared inspection fails. Browser responses are delivered after guarded transport, completeness and decoding checks; offline response inspection drains separately. Resource settling and runtime snapshots do not wait behind that analysis queue. Debugger capture excludes only proven owned bootstrap/isolated helper context, deduplicates exact bodies and keeps per-resource analyzer status and explicit capture budgets. Malformed/large inputs retain independent direct/decoded inspection.

See TEST_RESULTS.md, REPAIR_DIAGNOSIS.md and benchmarks/repair-verification.json for measured results and remaining limitations. Local fixture results are not real-world accuracy claims.
