Launch `Start Exposure Desk.cmd`. In New scan → Advanced, enable **Adapt allocations per website**. Entered shared and website maxima stay fixed. Save a project to reuse settings in queues and schedules. CLI: `runtime\node.exe dist\src\cli.js scan --config adaptive.config.example.json --sizing adaptive --output reports\new-scan.json`. Replace example URLs with your approved scope.

Adaptive mode preserves duration, request rate, concurrency, scope, bytes and memory bounds. Fixed mode uses entered maxima. Website-count mode preserves previous shared-cap scaling; old `autoScaleByWebsiteCount` configs remain supported, and explicit `sizingMode` wins. A website means one approved exact HTTP(S) origin. Old scan/checkpoint/history schemas remain compatible.
